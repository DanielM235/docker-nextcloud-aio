# Environment Variables (vanilla)

Complete reference for `.env`. Copy `.env.example` to `.env` and adjust.

## Compose

| Variable | Default | Description |
|----------|---------|-------------|
| `COMPOSE_PROJECT_NAME` | `nextcloud-vanilla` | Prefix for containers, volumes, networks. |

## Images

| Variable | Default | Description |
|----------|---------|-------------|
| `NEXTCLOUD_IMAGE_TAG` | `34.0.3-apache` | Official `nextcloud` image (apache variant). Upgrade one major at a time. |
| `MARIADB_IMAGE_TAG` | `11.4` | MariaDB LTS. |
| `REDIS_IMAGE_TAG` | `7-alpine` | Redis. |
| `PULL_POLICY` | `if_not_present` | `always` \| `if_not_present` \| `never`. |

## Domain / networking

| Variable | Default | Description |
|----------|---------|-------------|
| `DOMAIN_NAME` | `nextcloud.example.com` | Public hostname; also the Nextcloud trusted domain. |
| `APP_HTTP_PORT` | `8080` | Loopback port the app publishes; nginx proxies to it. |
| `OVERWRITECLIURL` | `https://nextcloud.example.com` | Base URL Nextcloud reports to clients. |

## Secrets (generated by `./setup.sh install`)

| Variable | Description |
|----------|-------------|
| `MYSQL_ROOT_PASSWORD` | MariaDB root password. |
| `MYSQL_PASSWORD` | Password for the `MYSQL_USER` database user. |

## Database

| Variable | Default | Description |
|----------|---------|-------------|
| `MYSQL_DATABASE` | `nextcloud` | Database name. |
| `MYSQL_USER` | `nextcloud` | Database user. |

## Initial admin (optional)

| Variable | Default | Description |
|----------|---------|-------------|
| `NEXTCLOUD_ADMIN_USER` | *(empty)* | Set both to auto-install and skip the web wizard. |
| `NEXTCLOUD_ADMIN_PASSWORD` | *(empty)* | — |

## Data directory (external disk)

| Variable | Default | Description |
|----------|---------|-------------|
| `NEXTCLOUD_DATA_DIR` | `/mnt/nextcloud-data` | Host path (bind mount) for user files. Mount the external disk first; `./setup.sh install` creates and chowns it to `www-data` (uid 33). |

## Redis

| Variable | Default | Description |
|----------|---------|-------------|
| `REDIS_HOST` | `redis` | Redis service name (fixed, internal). |
| `REDIS_HOST_PASSWORD` | *(generated)* | `requirepass` for the Redis container, also passed to Nextcloud. Auto-generated by `./setup.sh install`. |

## PHP / upload tuning

| Variable | Default | Description |
|----------|---------|-------------|
| `PHP_MEMORY_LIMIT` | `512M` | PHP memory limit. |
| `PHP_UPLOAD_LIMIT` | `16G` | `post_max_size` / `upload_max_filesize`. |
| `APACHE_BODY_LIMIT` | `0` | Apache request body limit in bytes (`0` = unlimited). |

## Resources

| Variable | Default | Description |
|----------|---------|-------------|
| `DB_CPU_LIMIT` / `DB_MEM_LIMIT` | `2.0` / `1g` | MariaDB limits. |
| `REDIS_CPU_LIMIT` / `REDIS_MEM_LIMIT` | `0.5` / `256m` | Redis limits. |
| `APP_CPU_LIMIT` / `APP_MEM_LIMIT` | `2.0` / `1g` | Nextcloud limits. |
| `CRON_CPU_LIMIT` / `CRON_MEM_LIMIT` | `0.5` / `512m` | Cron limits. |

## Restart / logging

| Variable | Default | Description |
|----------|---------|-------------|
| `RESTART_POLICY` | `unless-stopped` | Restart policy. |
| `LOG_DRIVER` | `json-file` | Logging driver. |
| `LOG_MAX_SIZE` | `10m` | Log rotation size. |
| `LOG_MAX_FILE` | `5` | Rotated files kept. |

## Backup

| Variable | Default | Description |
|----------|---------|-------------|
| `BACKUP_DIR` | `backups` | Backup directory (relative to this config). |
| `BACKUP_RETENTION_DAYS` | `30` | Retention in days. |
